# 실제 영상 평가에 따른 개선 계획과 반영 결과

## 조사한 문서와 범위

`V02_IMPLEMENTATION.md`, `CONTRACT.md`, `README.md`, `docs/v02-evaluation.md`와
`docs/development-status.md`와 로컬 실제 영상 평가를 함께 확인했다. PR-01~04는 구현된 상태였지만, 실제
영상에서는 다음 단계가 불분명한 입력 화면과 프레임 탐색 대기가 남았다.
이번 변경은 기준점 입력 안내와 PR-05의 구간 디코딩·빠른 탐색·캐시·썸네일을 반영한다.
선·원호 정합이나 선수 추적까지 완료한 것으로 해석하면 안 된다.

| 확인한 문제 | 반영한 변경 | 확인 방법 |
| --- | --- | --- |

## 입력 화면의 좌표 의미

이름으로 선택할 수 있는 지점은 코너 4개, 중앙선과 양 터치라인의 교차점
2개, 중심점이다. 이 지점의 정규화 좌표는 필드 치수에 따라 바뀌지 않는다.
원본의 점을 먼저 찍고 같은 기준점을 선택하여 연결한다. 자유 좌표 입력도
유지한다. 화면의 좌우와 그림의 좌우를 일관되게 대응시켜야 한다.

센터서클, 페널티 영역과 골대는 규격 미확인 참고도이며 점선으로 구분한다.
예시 치수로 실제 관측 좌표를 생성하거나 치수 검증 상태를 변경하지 않는다.
이름으로 선택하는 목록에도 원·페널티 영역의 추정 지점을 넣지 않는다.
따라서 두 개의 원·선 교차점만 보이는 프레임에서 정합이 가능해진 것은 아니다.

## 프레임 정확성과 자원 한도

- 인덱스와 원본 PTS가 기준이다. 추정 FPS로 프레임 번호를 다시 계산하지 않는다.
- 모든 PTS가 원본이며 엄격하게 증가하고 정확히 표현 가능한 경우에만 빠른
  탐색을 시도한다. FFmpeg의 자동 시각 절삭을 끄고 정확한 PTS 필터로 고른다.
- PTS가 누락·중복되거나 탐색에 실패하면 기존 순차 디코딩으로 돌아간다.
- 서버 캐시는 최대 32개·128 MiB, 브라우저 캐시는 최대 8개·추정 96 MiB다.
  브라우저 한도에는 압축 크기와 RGBA 크기를 합산한다. 전체 프로세스 메모리의
  상한은 아니며, 활성 이미지와 진행 중 요청은 별도다.
- 캐시는 메모리에만 유지한다. 저장 이력과 SQLite의 과거 분석은 변경하지 않는다.
- 전파 구간은 한 번에 최대 31프레임·64 MiB 원시 픽셀 창으로 읽는다. 단일
  프레임이 한도를 넘으면 한 프레임을 허용한다. 역방향도 같은 인덱스를 사용한다.
  상주 디코더는 없고, 창 디코딩 프로세스는 다음 관측 계산 전에 종료된다.
  변환 중 PNG 버퍼와 FFmpeg 메모리는 별도다. 10비트 원본도 기존 PNG 인코딩과
  OpenCV 변환을 사용하여 색상 양자화 차이를 피한다.
- 썸네일은 최대 320×180 JPEG이며 원본 PNG와 서버 캐시 한도를 공유한다.
  접힌 상태에서는 요청하지 않고, 정밀 입력에는 항상 원본 프레임을 사용한다.

## 검증 결과

2026-09-09 Windows 로컬 검사: Python 29개, Node 12개, 브라우저 DPR 2 및
모바일 검사 통과. B프레임, VFR, 0이 아닌 시작 PTS, 회전 영상의 선택 프레임이
순차 디코딩과 픽셀 단위로 같았다. 10비트 영상과 정방향·역방향 구간도 검증했다.
캐시 용량·LRU·동시 요청·실패 후 재시도,
원본 변경 거부와 인덱스 재사용도 검사했다.

## 남은 개선과 완료 조건

1. 선·원호 기반 정합: 선의 이름과 관측 구간, 원·호의 규격 근거, 관측/예측 구분을
   먼저 계약으로 정의한다. 제약이 부족한 장면은 여러 해가 가능하므로 점 두 개만
   있어도 사용할 수 있다는 식으로 처리하지 않는다. 별도 관측을 통한 검증이 필요하다.
2. 인접 프레임 선행 로딩: 구간 디코딩·빠른 개별 탐색·캐시·썸네일은 반영했다.
   상주 디코더와 편집기 선행 로딩은 후속 측정에 따라 결정한다. 작업 취소·메모리
   한도·정확한 PTS 검증을 유지하면서 추가 이득을 확인해야 한다.
3. 실제 사용성·정합 평가: 반복 작업의 사용자 조작 시간, 포기/수정 횟수와 독립된
   경기장 좌표 오차를 기록한다. 이번 픽셀 일치 검사는 영상 프레임의 정확성만 확인한다.
